The preparation workspace has no Rust compiler or Docker engine. Normal attempts to reach the Rust distribution and Cargo index download hosts timed out. Current release documentation was accessible for version checks, but that does not resolve or compile a dependency graph.

The stale dependency-free lockfile was removed. A real lockfile must be generated by Cargo. Initial Docker and CI builds are configured to do this; a supplied lockfile is used with `--locked`. A fabricated lockfile would not be evidence of a successful build.

Passing Python/static checks does not establish Rust type correctness, API compatibility, runtime authentication, concurrent behavior, shutdown guarantees, image build success, or container readiness. A successful run of the supplied native and Docker checks is still required before claiming this package works end to end.
